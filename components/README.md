# Components

Each component is its own Maven project in a folder here:

| Folder | Component |
|---|---|
| `products/` | Products |
| `customers/` | Customers |
| `orders/` | Orders |
| `delivery/` | Delivery & Logistics |
| `inventory/` | Inventory / Warehousing |
| `reviews/` | Reviews & Ratings |
| `finance/` | Finance & Reporting |

Only work in your own folder. See the [Team Guide](../docs/TEAM-GUIDE.md), step 5.
